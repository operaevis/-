# OPERAE VIS — Prototype Web (`operaevis.com`)

Prototype statique de présentation et de console simulée pour **OPVS (Operae Vis System)**.

- Parité fondamentale : `1 OPVS = 1 kWh = 3,6 MJ` (`1 µOPVS = 3,6 J`, entiers uniquement).
- Données de la console : jeu simulé illustratif (hors télémétrie site réel).
- Fondateur & Inventeur : Canius, Antoine De Cagny.
